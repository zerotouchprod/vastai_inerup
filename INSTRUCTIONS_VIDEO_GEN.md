## 🔍 Отладка

### Если инстанс не запускается:
1. Проверьте баланс Vast AI
2. Проверьте API ключ: `echo $VAST_API_KEY`
3. Проверьте веб-интерфейс: https://cloud.vast.ai/instances/

### Если генерация не работает:
1. Подключитесь по SSH: `ssh -p <PORT> root@<HOST>`
2. Проверьте рабочую директорию: `cd /workspace && ls -la`
3. Проверьте код: `ls -la src/entrypoints/`
4. Попробуйте запустить с `--help`: `python -m src.entrypoints.run_gen --help`

### Если нет SSH доступа:
1. Дождитесь полной загрузки Docker образа
2. SSH порт появится только при статусе `running`
3. Проверьте статус: `python3 check_instance_status.py`
