## Следующий Шаг

**Запусти команду снова.** Теперь увидишь:

```
[ProPainterAdapter] STDERR (full): <полное сообщение до 5000 символов>

```

Это покажет **реальную** причину, и мы применим **правильное** решение:

| Если тип | Значит | Решение |
|----------|--------|---------|
| OUT_OF_MEMORY | Нехватка памяти | Nuclear settings (активны) или 720p |
| IMPORT_ERROR | ProPainter сломан | Переустановка |
| CUDA_ERROR | Несовместимость | Переустановка PyTorch |
| RUNTIME_ERROR | Другое | Анализ полного лога |

## Быстрое Решение (Если Надоело)

**Используй 720p preprocessing** - работает в 95% случаев:

```bash
ffmpeg -i input.mp4 -vf "scale=-1:720" -crf 18 input_720p.mp4
# Затем обрабатывай input_720p.mp4
```

**Почему лучше:**
- ✅ Работает независимо от причины краша
