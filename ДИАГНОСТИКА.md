## Возможные Причины (не только OOM!)

### 1. **Out of Memory (OOM)** - моя первая гипотеза
- RAFT создает большие корреляционные тензоры
- Симптомы: `CUDA out of memory`, `RuntimeError: CUDA error`
- **НО:** мы не видим этого в логах!

### 2. **Import Error** - более вероятно!
- CorrBlock не может быть импортирован
- Симптомы: `ModuleNotFoundError`, `ImportError`, `AttributeError`
- Возможно: неправильная установка ProPainter или RAFT

### 3. **CUDA Version Mismatch**
- PyTorch скомпилирован для одной версии CUDA, установлена другая
- Симптомы: `RuntimeError: CUDA error`, молчаливый крах
- Возможно: CUDA 11.8 vs 12.x конфликт

### 4. **Missing Dependencies**
- Отсутствуют библиотеки: spatial_correlation_sampler, alt_cuda_corr
- Симптомы: `ModuleNotFoundError` при импорте CorrBlock
