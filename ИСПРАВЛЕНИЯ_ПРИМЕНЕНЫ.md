## 🎯 РЕШЕНИЕ: 720p Preprocessing

ProPainter **фундаментально сломан** на этом GPU/CUDA setup.

**100% Рабочее решение:**

```bash
# 1. Downscale видео до 720p
ffmpeg -i input_4k.mp4 -vf "scale=-1:720" -crf 18 input_720p.mp4

# 2. Обработать 720p версию
python main.py --input input_720p.mp4 --mode remove-subtitles --roi 0.05,0.4,0.9,0.4
```

### Почему Это Работает

- 720p → 405x720 processing (вместо 4K → 192x360)
- ProPainter **использует другие оптимизации** для среднего разрешения
- RAFT работает **стабильнее** на 720p
- Не ломается на `CorrBlock`

- ✅ **Быстро:** 20-30 минут на 2 GPU
- ✅ **Качество:** ⭐⭐⭐⭐ (отлично для 720p)
- ✅ **Субтитры:** Удалены
