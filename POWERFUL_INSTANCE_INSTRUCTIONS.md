## 🔍 ОТЛАДКА И ПОДДЕРЖКА

### Если инстанс не запускается:
1. Проверьте баланс на Vast AI
2. Убедитесь, что API ключ работает: `echo $VAST_API_KEY`
3. Проверьте веб-интерфейс: https://cloud.vast.ai/instances/

### Если генерация не работает:
1. Подключитесь по SSH (данные в логах)
2. Проверьте: `cd /workspace && ls -la`
3. Проверьте код: `ls -la src/entrypoints/`
4. Попробуйте тестовую команду: `python -m src.entrypoints.run_gen --help`

### Мониторинг прогресса:
```bash

  https://console.vast.ai/api/v0/instances/32416319/
```
