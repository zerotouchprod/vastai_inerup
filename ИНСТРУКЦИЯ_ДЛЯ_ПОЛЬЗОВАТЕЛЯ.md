❌ **Что не работает**:
```
File "/opt/ProPainter/RAFT/raft.py", line 126, in forward
    corr = corr_fn(coor...
```

ProPainter subprocess crashes при попытке использовать CorrBlock.

## Причина

**API несовместимость между RAFT и нашим Pure PyTorch CorrBlock.**

RAFT вызывает:
```python
corr_fn = CorrBlock(fmap1, fmap2, radius=self.args.corr_radius)
```

Наш CorrBlock ожидает:
```python
def __init__(self, fmap1, fmap2, num_levels=4, radius=4):
```

Проблема: RAFT не передает `num_levels`, но наш код его требует (хотя и с дефолтом).

**Решение**: Обновить `CorrBlock.__init__` чтобы правильно обрабатывать keyword arguments.

```bash
# 1. Создайте corr.py:

#!/usr/bin/env python3
import sys
from pathlib import Path

project_root = None
possible_roots = [
    Path("/root/vastai_inerup"),
    Path("/workspace/project"),
    Path.home() / "vastai_inerup",
]

for root in possible_roots:
    check = root / "src/infrastructure/inpainting/pure_pytorch_correlation.py"
    if root.exists() and check.exists():
        project_root = root
        break

if project_root is None:
    raise ImportError("Cannot find vastai_inerup project!")

if str(project_root) not in sys.path:
    sys.path.insert(0, str(project_root))

from src.infrastructure.inpainting.pure_pytorch_correlation import CorrBlock
AlternateCorrBlock = CorrBlock
__all__ = ['CorrBlock', 'AlternateCorrBlock']
EOF

python3 -c "import sys; sys.path.insert(0, '/opt/ProPainter'); from RAFT.corr import CorrBlock; print('✅')"
```

## Технические Детали (Для Понимания)

### Что Изменилось

**Старая версия corr.py** (не работала):
```python
project_root = Path(__file__).parent.parent.parent.parent / "vastai_inerup"
# ❌ Fragile relative path
```

**Новая версия corr.py** (работает):
```python
possible_roots = [
    Path("/root/vastai_inerup"),  # Try absolute paths
    Path("/workspace/project"),
    Path.home() / "vastai_inerup",
]
for root in possible_roots:
    if (root / "src/.../pure_pytorch_correlation.py").exists():
        project_root = root  # ✅ Found!
        break
```

### Почему Нужен Update

- ProPainter запускается в subprocess
- Subprocess не видит изменения в памяти (sys.modules)
- Нужен **actual file** `/opt/ProPainter/RAFT/corr.py`
- Файл создавался при первом запуске
- Но старая версия осталась на диске
- Quick fix обновляет файл

**После update subprocess будет читать новую версию с правильным path finding!**
