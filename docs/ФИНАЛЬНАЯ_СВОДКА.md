## 📝 Изменения в Dockerfile

### Что Было (НЕ работало):
```dockerfile
FROM nvidia/cuda:12.9.0-cudnn-runtime-ubuntu22.04  # ❌ No compiler
# Missing: gcc, g++, cmake, python3-dev

# ProPainter install:
cd /opt/ProPainter/RAFT
pip install -e .  # ❌ ERROR: no setup.py
```

**Результат:**
- nvcc not found
- Can't build spatial-correlation-sampler
- ProPainter crashes on CorrBlock

---

### Что Стало (РАБОТАЕТ):
```dockerfile
FROM nvidia/cuda:12.9.0-cudnn-devel-ubuntu22.04  # ✅ Includes compiler

# Added build tools:
RUN apt-get install -y \
    build-essential \
    gcc g++ make cmake ninja-build \
    python3-dev

# ProPainter install (simplified):
pip install -r requirements.txt  # Installs pre-built (wrong CUDA)
pip uninstall spatial-correlation-sampler  # Remove old
pip install spatial-correlation-sampler  # ✅ Builds for CUDA 12.8
```

**Результат:**
- ✅ nvcc available
- ✅ spatial-correlation-sampler builds correctly
- ✅ ProPainter works on 4K

## 🚀 Как Использовать

### Вариант 1: Собрать Новый Image (Правильно)

```bash
cd /apps/PycharmProjects/vastai_interup_ztp/docker

# CUDA 12.8 (большинство vast.ai)
docker build -f Dockerfile.vastai.optimized -t vastai-interup:cuda128-fixed .
docker push yourusername/vastai-interup:cuda128-fixed

# CUDA 13.0 (RTX 50 series)
docker build -f Dockerfile.vastai.optimized.cuda130 -t vastai-interup:cuda130-fixed .
docker push yourusername/vastai-interup:cuda130-fixed
```

**Time:** 40-90 минут (первая сборка)  
**Size:** ~8-10GB (devel image больше runtime)  
**Result:** ProPainter работает на 4K навсегда

### Вариант 2: Quick Fix на Instance

```bash
# SSH в vast.ai
ssh -p PORT root@ssh.vast.ai

# Install build tools
apt-get update && apt-get install -y build-essential python3-dev

# Rebuild spatial-correlation-sampler
pip uninstall -y spatial-correlation-sampler
pip install --no-cache-dir spatial-correlation-sampler

# Verify
python3 -c "import spatial_correlation_sampler; print('✅ OK')"

# Test ProPainter
cd /root/vastai_inerup
python main.py --input video.mp4 --mode remove-subtitles --roi 0.05,0.4,0.9,0.4
```

**Time:** 10-15 минут  
**Note:** Теряется при рестарте контейнера  
**Result:** Работает временно

---

### Вариант 3: 720p Workaround (Всегда Работает)

```bash
# Downscale и обработать
ffmpeg -i input_4k.mp4 -vf "scale=-1:720" -crf 18 input_720p.mp4
python main.py --input input_720p.mp4 --mode remove-subtitles --roi 0.05,0.4,0.9,0.4
```

**Time:** 5 минут + 20-30 минут  
**Result:** 720p output (отличное качество)  
**Advantage:** Не требует rebuild
