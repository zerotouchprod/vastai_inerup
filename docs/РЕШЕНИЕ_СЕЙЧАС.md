# 🎯 ПРОБЛЕМА НАЙДЕНА: CUDA_VISIBLE_DEVICES=0 на Vast.ai!

## TL;DR

**Проблема:** `CUDA_VISIBLE_DEVICES=0` установлена в окружении vast.ai  
**Решение:** Очистить переменную перед запуском или в коде  
**Результат:** 2 GPU вместо 1, обработка в 2 раза быстрее

## Что Показала Диагностика

```
✅ nvidia-smi видит 2 GPU (железо OK)
❌ PyTorch видит только 1 GPU (софт ограничен)
❌ Причина: CUDA_VISIBLE_DEVICES=0 в окружении vast.ai
```

## 3 Способа Исправить

### Способ 1: Через Environment Variable (Быстро)

```bash
# В терминале vast.ai перед запуском:
export CUDA_VISIBLE_DEVICES=0,1
# или просто очистить:
unset CUDA_VISIBLE_DEVICES

# Затем запустить обработку
python main.py ...
```

### Способ 2: В Коде (Постоянное решение)

Добавь в начало главного скрипта (`main.py` или где запускаешь):

```python
import os
os.environ['CUDA_VISIBLE_DEVICES'] = '0,1'  # ДО импорта torch!

# Затем остальные импорты
from src.application.orchestrator import ...
```

### Способ 3: Через Wrapper Script

Создай `run_with_multigpu.sh`:

```bash
#!/bin/bash
export CUDA_VISIBLE_DEVICES=0,1
python "$@"
```

Запускай через него:
```bash
chmod +x run_with_multigpu.sh
./run_with_multigpu.sh main.py --input video.mp4 ...
```

## Проверка

После любого из способов проверь:

```bash
# Проверка environment
echo $CUDA_VISIBLE_DEVICES
# Должно быть: 0,1 или пусто (не "0"!)

# Проверка PyTorch
python diagnose_multigpu.py
```

Должно показать:
```
✅ Multi-GPU support: ENABLED
GPU 0: NVIDIA GeForce RTX 3090 (23.6GB)
GPU 1: NVIDIA GeForce RTX 3090 (23.6GB)
Total VRAM: 47.2GB across 2 GPUs
```

## Запуск Обработки

После исправления:
```bash
# Способ 1: С export
export CUDA_VISIBLE_DEVICES=0,1
python main.py --input video.mp4 --mode remove-subtitles ...

# Способ 2: В одной строке
CUDA_VISIBLE_DEVICES=0,1 python main.py ...
```

Теперь будет:
- ✅ 2 GPU вместо 1
- ✅ Параллельная обработка chunks
- ✅ ~2x быстрее (493 frames за ~1.5 часа вместо 3 часов)

## Если Всё Равно OOM

Даже с 2 GPU может быть OOM на 4K portrait видео.

**Решение:** 720p preprocessing

```bash
ffmpeg -i input.mp4 -vf "scale=-1:720" -crf 18 input_720p.mp4
# Обрабатывай input_720p.mp4
```

Это даст:
- ✅ Обработку на ~405x720 (вместо ~203x360)
- ✅ 3-4x быстрее
- ✅ Лучше качество
- ✅ 95% успех

## Для Постоянного Решения

Добавь в начало `main.py` (или `src/presentation/cli.py`):

```python
# В самом начале файла, ДО всех импортов
import os
if os.environ.get('CUDA_VISIBLE_DEVICES') == '0':
    print("⚠️  Fixing CUDA_VISIBLE_DEVICES from '0' to '0,1' for multi-GPU")
    os.environ['CUDA_VISIBLE_DEVICES'] = '0,1'
```

Тогда будет работать автоматически при каждом запуске!
