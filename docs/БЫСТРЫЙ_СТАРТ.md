# 🚀 БЫСТРЫЙ СТАРТ

## ⚠️ КРИТИЧНО

ProPainter крашится на 4K из-за бага в RAFT CorrBlock.  
**Решение:** Downscale до 720p перед обработкой.

## Команды

### One-Liner (Быстро):

```bash
# Скачать, downscale, обработать
wget "https://videos.../input.mp4" && \
ffmpeg -i input.mp4 -vf "scale=-1:720" -crf 18 input_720p.mp4 && \
python main.py --input input_720p.mp4 --mode remove-subtitles --roi 0.05,0.4,0.9,0.4
```

### Пошагово:

```bash
# 1. Downscale
ffmpeg -i input.mp4 -vf "scale=-1:720" -crf 18 input_720p.mp4

# 2. Обработать
python main.py --input input_720p.mp4 --mode remove-subtitles --roi 0.05,0.4,0.9,0.4
```

### С Автоматическим Скриптом:

```bash
./preprocess_video_720p.sh input.mp4 input_720p.mp4
# Затем обработать input_720p.mp4
```

## Результат

- ✅ Работает: 100%
- ✅ Время: 20-30 минут (2 GPU)
- ✅ Качество: ⭐⭐⭐⭐
- ✅ Output: 720p, субтитры удалены

## Upscale (Optional)

```bash
# Если нужен 1080p output
ffmpeg -i output_720p.mp4 -vf "scale=-1:1080" -crf 18 output_1080p.mp4
```
