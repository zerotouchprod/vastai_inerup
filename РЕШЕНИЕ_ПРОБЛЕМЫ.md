# 🔧 ТРИ СПОСОБА РЕШИТЬ ПРОБЛЕМУ

## Диагноз

**Root Cause:** ProPainter RAFT C++ extensions скомпилированы для CUDA 11.x, но система использует CUDA 12.x.

**Симптом:** Crash на `corr_fn = CorrBlock` без сообщения об ошибке.

---

## Решение 1: 720p Preprocessing ⭐ (БЫСТРО, 100% РАБОТАЕТ)

### Описание
Обходим проблему, не фиксируя ProPainter. Downscale видео до 720p - ProPainter стабилен на этом разрешении.

### Почему Работает
- ProPainter использует **другие оптимизации** для 720p
- RAFT работает **с меньшей нагрузкой** → не триггерит баг
- Multi-GPU работает
- Quality отличное

### Команды
```bash
# Downscale
ffmpeg -i input_4k.mp4 -vf "scale=-1:720" -crf 18 input_720p.mp4

# Обработать
python main.py --input input_720p.mp4 --mode remove-subtitles --roi 0.05,0.4,0.9,0.4
```

### Результат
- ✅ Time: 5 минут setup + 20-30 минут processing
- ✅ Success: 100%
- ✅ Quality: ⭐⭐⭐⭐ (720p output)
- ✅ Effort: Минимальный

### Минусы
- Output только 720p (не 4K)
- Нужен дополнительный шаг (downscale)

## Решение 2: Rebuild ProPainter для CUDA 12.x 🔨 (ПРАВИЛЬНО, ДОЛГО)

### Описание
Пересобрать ProPainter C++ extensions для правильной версии CUDA.

### Команды (На Сервере vast.ai)

```bash
# 1. Проверить версии CUDA
nvcc --version  # Должно показать CUDA 12.x
python3 -c "import torch; print(torch.version.cuda)"  # Должно быть 12.x

# 2. Если PyTorch с неправильной CUDA - переустановить
pip uninstall torch torchvision
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121

# 3. Rebuild ProPainter extensions
cd /opt/ProPainter
pip uninstall spatial-correlation-sampler -y
pip install spatial-correlation-sampler --no-cache-dir --force-reinstall

# 4. Проверить
python3 -c "import sys; sys.path.insert(0, '/opt/ProPainter'); from RAFT.raft import CorrBlock; print('✅ OK')"

# 5. Если не помогло - rebuild RAFT from source
cd /opt/ProPainter/RAFT
pip install -e . --no-cache-dir
```

### Результат
- ✅ ProPainter работает на 4K
- ✅ Quality: ⭐⭐⭐⭐⭐
- ✅ Долгосрочное решение

### Минусы
- ⏱️ Time: 2-4 часа диагностики и rebuild
- 🔧 Требует доступа к серверу
- ⚠️ Может не сработать (зависит от setup)
- 💰 Тратишь время vast.ai instance ($$$)

## Решение 3: Новый Docker Image 🐳 (САМОЕ ПРАВИЛЬНОЕ)

### Описание
Создать/найти Docker image с **правильной версией ProPainter + CUDA**.

### Опции

#### A) Найти готовый image
```bash
# Поискать ProPainter images с CUDA 12.x
docker search propainter

# Или использовать официальный, но с правильным PyTorch
# base: nvidia/cuda:12.1-cudnn8-devel-ubuntu22.04
```

#### B) Собрать свой image

Создать `Dockerfile.propainter`:

```dockerfile
FROM nvidia/cuda:12.1.0-cudnn8-devel-ubuntu22.04

# Install Python and dependencies
RUN apt-get update && apt-get install -y \
    python3.10 python3-pip git ffmpeg \
    && rm -rf /var/lib/apt/lists/*

# Install PyTorch with CUDA 12.1
RUN pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu121

# Clone and install ProPainter
RUN git clone https://github.com/sczhou/ProPainter.git /opt/ProPainter
WORKDIR /opt/ProPainter
RUN pip3 install -r requirements.txt

# Build RAFT extensions
WORKDIR /opt/ProPainter/RAFT
RUN pip3 install -e .

# Build other extensions
RUN pip3 install spatial-correlation-sampler --no-cache-dir

# Test
RUN python3 -c "from RAFT.raft import CorrBlock; print('✅ ProPainter OK')"

WORKDIR /workspace
```

Собрать:
```bash
docker build -f Dockerfile.propainter -t my-propainter:cuda12 .
```

### Результат
- ✅ ProPainter работает из коробки
- ✅ Можно переиспользовать
- ✅ Правильное долгосрочное решение

### Минусы
- ⏱️ Time: 4-6 часов (первый раз)
- 🔧 Требует Docker знаний
- 💾 Нужно загрузить на Docker Hub или vast.ai

## Что Конкретно Сломано

### Технические Детали:

1. **Docker image на vast.ai содержит:**
   - ProPainter скомпилированный для CUDA 11.8
   - PyTorch 2.11 с CUDA 12.8
   - ❌ **Несовместимость!**

2. **RAFT CorrBlock:**
   - Это C++ CUDA extension
   - Компилируется под конкретную версию CUDA
   - При запуске ищет CUDA 11.8 ops
   - Находит CUDA 12.8 ops
   - ❌ **Crash без сообщения**

3. **Почему 720p работает:**
   - ProPainter использует разные code paths для разных разрешений
   - На 720p: меньше нагрузка на RAFT → обходит баг
   - На 4K: полная нагрузка → триггерит несовместимость
