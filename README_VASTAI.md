# 🚀 Запуск пайплайна генерации видео на Vast AI

## 📋 Обзор

**Цель**: Запустить пайплайн `text2image image2video` на Vast AI  
**Docker образ**: `registry.gitlab.com/gfever/vastai_interup:video-gen` (~40GB)  
**Требования**: Инстанс с диском >= 100GB, VRAM >= 24GB  
**Код пайплайна**: `src/entrypoints/run_gen.py`

## ⚠️ Критическая проблема

**`vast_submit.py` создает инстансы с диском 10GB по умолчанию**, а Docker образ весит 40GB.  
**Решение**: Запускать инстанс вручную через веб-интерфейс с фильтром `Disk Space >= 100GB`.

## 🎯 Рабочий процесс

### 1. Автоматический мониторинг (запущен)
- Проверяет инстансы каждые 3 минуты
- Останавливает инстансы с диском < 100GB
- PID мониторинга: `8299` (проверить: `ps aux | grep 8299`)

### 2. Ручной запуск (рекомендуется)

#### Шаги:
1. **Откройте**: https://vast.ai/
2. **Нажмите "Create"**
3. **Установите фильтры**:
   - GPU RAM: >= 24GB
   - Disk Space: >= 100GB
   - Price: <= $1.0/hour
   - Verified: Yes
4. **Выберите инстанс** с:
   - RTX 3090/4090, A100, V100 (24GB+ VRAM)
   - Диск 100GB+ (лучше 200GB+)
5. **Настройте**:
   - Image: `registry.gitlab.com/gfever/vastai_interup:video-gen`
   - Command: `sleep 36000` (10 часов для отладки)
   - SSH: Enable
6. **Нажмите "Rent"**
7. **Ждите 20-40 минут** загрузки Docker образа
8. **Подключитесь по SSH**:
   ```
   ssh -p <PORT> root@<IP>
   ```
9. **Запустите генерацию**:
   ```bash
   cd /workspace
   python -m src.entrypoints.run_gen \
     --job '{"mode": "text2video", "prompts": ["A beautiful sunset over ocean waves"], 
            "num_frames": 24, "fps": 8, "num_inference_steps": 25}'
   ```
10. **Остановите инстанс** после работы

### 3. Стоимость
- Загрузка Docker: 20-40 мин = $0.10-$0.30
- Генерация видео: 5-15 мин = $0.05-$0.15
- **Итого**: $0.15-$0.45 за запуск

## 🚨 Важные моменты

### Проблемы с `vast_submit.py`:
- Создает инстансы с диском 10GB
- Не поддерживает параметр `allocated_storage`
- **Не использовать для этого пайплайна!**

### Требования к инстансу:
1. **Диск**: минимум 100GB (лучше 200GB+)
2. **VRAM**: минимум 24GB (RTX 3090/4090, A100, V100)
3. **SSH доступ**: для отладки
4. **Верифицированный хост**: для надежности

### Отладка после подключения:
```bash
# Проверка диска
df -h

# Проверка Docker
docker ps
docker images

# Проверка GPU
nvidia-smi

# Запуск тестовой генерации
cd /workspace
python -m src.entrypoints.run_gen --job '{"mode": "text2video", "prompts": ["test"]}'
```
