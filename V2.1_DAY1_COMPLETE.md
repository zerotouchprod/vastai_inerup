## 🎓 Technical Highlights

### Optical Flow Algorithm (Farneback)

**Why Farneback?**
- ✅ Dense flow (vectors for every pixel)
- ✅ Fast (OpenCV optimized C++ implementation)
- ✅ No feature detection needed
- ✅ Works well for text tracking

**Parameters:**
```python
pyr_scale=0.5      # Pyramid scale (smaller = more levels)
levels=3           # Number of pyramid levels
winsize=15         # Averaging window size
iterations=3       # Iterations at each level
poly_n=5           # Polynomial expansion size
poly_sigma=1.2     # Gaussian sigma for smoothing
```

### Keyframe Strategy

**Concept:**
Instead of OCR on every frame (expensive), we:
1. Detect text in keyframes (every 5 frames)
2. Propagate mask with optical flow (cheap) between keyframes
3. Result: 5x fewer OCR calls!

**Math:**
```
Without propagation: 150 frames × 150ms = 22,500ms
With propagation:    30 OCR × 150ms + 120 flow × 50ms = 10,500ms
Speedup:            22,500 / 10,500 = 2.14x
```

### Color Change Detection (HSV)

**Why HSV instead of RGB?**
- Hue channel = pure color (independent of brightness)
- Saturation channel = color intensity
- Value channel = brightness

**Karioke Detection:**
Text changes from white → yellow → green
```
HSV Histogram std(Hue) > threshold → "karaoke"
```

### **Recommendation 3: Memory Monitoring + Adaptive Scaling** 💾 PRIORITY 1

**Architect Warning:** "На 4K видео это может съесть много RAM"

**Problem:**
- 4K flow = ~1.4GB memory
- Computation time: 400ms vs 50ms @ 720p

**Solution: Adaptive Downscaling**
```python
# Downscale for flow computation
4K (3840x2160) → HD (1280x720)
Flow computed @ 720p → upscaled to 4K
Result: 9.3x less memory, 8x faster
```

**Expected Memory Usage:**

| Resolution | Without Scaling | With Scaling | Speedup |
|------------|----------------|--------------|---------|
| 640x480 | ~50MB | ~50MB | 1x |
| 1280x720 | ~150MB | ~150MB | 1x |
| 1920x1080 | ~350MB | ~150MB | 2.3x |
| 3840x2160 | ~1.4GB | ~150MB | **9.3x** ⚡ |

**Implementation:**
```python
def _maybe_downscale(self, frame, max_dimension=1280):
    if max(frame.shape[:2]) > max_dimension:
        scale = max_dimension / max(frame.shape[:2])
        return cv2.resize(frame, ...), scale
    return frame, 1.0
```
