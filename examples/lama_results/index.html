About LaMa Inpainting

LaMa (Large Mask Inpainting) is a deep learning model for image inpainting that can remove objects or text from images while preserving context and texture.

This example demonstrates how LaMaAdapter integrates into the vastai_inerup project for subtitle removal in videos.

Key features:

  • High-quality inpainting even with large masks
  • Fast inference with GPU acceleration
  • ROI optimization for processing only relevant regions
  • Integration with the project's clean architecture
